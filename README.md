# Spawn

Spawn is a simple and customizable Spigot Minecraft plugin for setting a spawn that can be teleported to at any time

## Commands

> The commands that are included with the plugin

- /spawn
  - The main command that can teleport players to the spawn
  - Can also be used to teleport other players and reload the config

- /setspawn
  - The command to set the spawn
